# Telecom Customer Churn Analysis Dashboard

My **first Power BI dashboard project**, where I analyzed telecom customer churn and turned raw data into actionable business insights. This project helped me learn the complete dashboard-building workflow, from data cleaning to DAX and visualization.

## Key Highlights

* **Total Customers:** 7,043
* **Churn Rate:** 26.54%
* Month-to-Month contracts showed the highest churn.
* Customers with **0–6 months** tenure had the highest churn rate.
